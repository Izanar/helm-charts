# Mediapulse Helm Charts

Репозиторий чартов Mediapulse, обслуживается [chart-releaser](https://github.com/helm/chart-releaser).

```bash
helm repo add mediapulse https://izanar.github.io/helm-charts
helm repo update
helm search repo mediapulse
```

Исходники и README: ветка [main](https://github.com/Izanar/helm-charts).
